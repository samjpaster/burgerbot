# Bob's Burgers Discord Bot

A Discord bot themed around the animated TV show *Bob's Burgers*. It automatically posts a daily "Burger of the Day" to a configured channel and provides slash commands to explore burgers, episodes, and characters — all powered by the [Bob's Burgers API](https://bobsburgers-api.herokuapp.com).

## Features

- **Daily Burger of the Day** — automatically posts a burger embed to a channel at a configured time each day
- **No repeats** — the bot tracks every posted burger and cycles through all 416+ before resetting
- **Two independent burger pools** — the daily scheduler and the `/burger-of-the-day` command each maintain their own pool, so manual requests don't consume the daily post's queue
- **Slash commands** for on-demand content: burgers, episodes, and characters with quotes

## Slash Commands

| Command | Description |
|---|---|
| `/burger-of-the-day` | Get a random Burger of the Day on demand |
| `/burgers-left` | See how many burgers have been posted vs. remaining in each pool |
| `/burger-help` | Display all available commands |
| `/random-episode` | Get a random episode with details (air date, viewers, description) |
| `/random-character [name]` | Get a random (or named) character with a random quote |

## Project Structure

```
burgers/
├── bot.py                  # Entry point — initializes and runs the bot
├── config.py               # Loads environment variables
├── api.py                  # Async HTTP client for the Bob's Burgers API
├── db.py                   # Async SQLite database layer for tracking posted burgers
├── scrape_quotes.py        # Standalone script to scrape character quotes from the Fandom wiki
├── all_burgers.json        # Local snapshot of all 416+ burgers from the show
├── character_quotes.json   # Character quotes (generated by scrape_quotes.py)
├── requirements.txt
├── .env.example
└── cogs/
    ├── burgers.py          # Burger of the Day commands + daily scheduler
    ├── episodes.py         # Random episode command
    └── characters.py       # Random character + quote command
```

## Setup

### Prerequisites

- Python 3.10+
- A Discord bot token from the [Discord Developer Portal](https://discord.com/developers/applications)

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure Environment

Copy `.env.example` to `.env` and fill in your values:

```env
DISCORD_TOKEN=your-discord-bot-token
BURGER_CHANNEL_ID=your-discord-channel-id
POST_TIME=17:00        # Optional — defaults to 17:00 UTC (12:00 EST)
```

### 3. (Optional) Scrape Character Quotes

Run this once to populate `character_quotes.json`, which is required for the `/random-character` command:

```bash
python scrape_quotes.py
```

### 4. Run the Bot

```bash
python bot.py
```

The bot logs to both the console and a rotating `bot.log` file (max 5 MB, 3 backups).

| `aiosqlite` | Async SQLite for tracking burger pools |
| `python-dotenv` | `.env` configuration loading |

- `https://bobs-burgers.fandom.com/api.php` — character quotes (used by the scraper)
