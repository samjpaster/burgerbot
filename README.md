# Bob's Burgers Discord Bot

A Discord bot themed around the animated TV show *Bob's Burgers*. It automatically posts a daily "Burger of the Day" to a configured channel and provides slash commands to explore burgers, episodes, and characters — all powered by the [Bob's Burgers API](https://bobsburgers-api.herokuapp.com) and the Bob's Burgers Fandom wiki.

---

## Features

- **Daily Burger of the Day** — automatically posts a burger embed to a configured channel at 12:00 EST (17:00 UTC) every day
- **No-repeat pools** — the bot cycles through all 416 burgers before resetting; once exhausted, the pool resets and starts over
- **Two independent burger pools** — the daily scheduler and the `/burger-of-the-day` command each maintain their own separate pool, so manual requests never consume the scheduled post's queue
- **Random episode lookup** — pulls a random episode with air date, viewer count, and description
- **Character quotes** — 296 characters with quotes scraped from the Fandom wiki, including all main cast
- **Headless operation** — runs via `pythonw.exe` with no console window; all output written to a rotating log file
- **Persistent state** — burger pool progress is stored in SQLite and survives bot restarts

---

## Slash Commands

| Command | Description |
|---|---|
| `/burger-of-the-day` | Pull a random Burger of the Day on demand (own no-repeat pool) |
| `/burgers-left` | Show how many burgers have been posted and how many remain in each pool |
| `/burger-help` | List all available commands |
| `/random-episode` | Get a random Bob's Burgers episode with air date, viewers, and description |
| `/random-character [name]` | Get info and a random quote for a character; omit `name` for a fully random pick |

## Setup

### Prerequisites

- Python 3.11+
- A Discord bot token from the [Discord Developer Portal](https://discord.com/developers/applications)

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure environment

Copy `.env.example` to `.env` and fill in your values:

```env
DISCORD_TOKEN=your-discord-bot-token
BURGER_CHANNEL_ID=your-discord-channel-id
POST_TIME=17:00        # UTC — 17:00 UTC = 12:00 EST
```

### 3. Scrape character quotes

Run this once to populate `character_quotes.json`. This is required for the `/random-character` command.

```bash
python scrape_quotes.py
```

The script fetches all 598 characters from the API and queries the [Fandom MediaWiki API](https://bobs-burgers.fandom.com/api.php) for each character's `/Quotes` page. It takes a few minutes to run and produces 296 characters with quotes including the full main cast (Bob, Linda, Tina, Gene, Louise, Teddy, Gayle, and many more).

To refresh the quotes at any point (e.g. after new episodes air), simply run the script again.

### 4. Run the bot

```bash
python bot.py
```

To run headlessly with no console window (Windows):

```bash
pythonw.exe bot.py
```

The bot logs to both the console and `bot.log` (rotating, 5 MB max, 3 backups).

## Implementation Details

### Burger pools

Two SQLite tables — `scheduled_burgers` and `requested_burgers` — track which burger IDs have been posted for each pool independently. When a pool is exhausted, it resets automatically and the embed footer notes the wrap-around.

### Daily scheduler

Uses `nextcord`'s `tasks.loop(time=...)` to fire at a fixed UTC time. The task waits for the bot to be ready before starting, and cancels cleanly on cog unload.

### Character quotes scraper

The Fandom wiki blocks direct HTML scraping (403). The scraper instead uses the **MediaWiki API** (`action=parse&prop=wikitext`) to retrieve raw wikitext, then extracts quotes with a regex match on `{{Quote|text|...}}` templates. Wiki markup (`[[links]]`, `''italics''`, `<ref>` tags) is stripped before saving.

### Logging

All significant events — slash command invocations (with user, channel, timestamp), daily post, pool resets, API errors — are logged at `INFO` level to both the console and the rotating file handler.

## Technologies

|---|---|
